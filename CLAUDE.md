# Encore Skills - Agent Instructions

This repository contains skills for building backend applications with Encore.ts and Encore.go.

## What is Encore?

Encore.ts and Encore.go are backend frameworks where code defines infrastructure. Write your application → Encore provisions databases, Pub/Sub, cron jobs, and more in your AWS/GCP account automatically.
